# Santhosh & Sanjhana — A Wedding Story

A beautiful, editorial-style wedding photo gallery built with TanStack Start, React 19, and Tailwind CSS v4.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
